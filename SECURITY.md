# Security policy

Report a vulnerability privately through [GitHub's security advisory form](https://github.com/jeremykenedy/aqua-surface-drift/security/advisories/new). Include the affected version, device/Android version if relevant, and steps to reproduce. Do not include personal data or device identifiers.

The app makes no runtime network requests. The optional installer retrieves a release from this repository and verifies its SHA-256 before installation.
