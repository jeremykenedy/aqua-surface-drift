# Aqua Surface Drift 1.0.0

Initial stable release of the continuously animated water-surface screensaver.

## Included

- Flowing wave contours and optional moving sunlight reflections, drawn on device.
- Ocean, lagoon, and pool environments with daylight, dusk, and night lighting.
- Calm, natural, and lively ripple density, plus motion speed and close/wide view controls.
- Independent Random choices and a global randomize-on-start option.
- Android DreamService, remote-friendly settings screen, live preview, and settings provider.
- Standalone checksum-verifying ADB install/update/uninstall tool.

## Compatibility and verification

The app targets API 23 and later. An Android TV emulator was used to verify installation, settings, and animated preview rendering at 1920x1080. Emulator system screensaver selection was unavailable. Physical Fire TV and Google TV activation and native 4K behavior remain untested. See [device verification](../VERIFICATION.md) and the issue tracker if you can test either platform.

## Upgrade

Install or update with `python3 install.py --serial TV_IP:5555`. The installer preserves system screensaver selection and timers. For a manual download, verify the attached checksum:

```bash
shasum -a 256 -c aqua-surface-drift.apk.sha256
```

This first release has no migrations or breaking changes.
